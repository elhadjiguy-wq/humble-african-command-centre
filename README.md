# HUMBLE AFRICAN Business Command Centre

A simple, revenue-first operating dashboard for **HUMBLE AFRICAN** — *Rooted in Africa. Made for everyone.*

The dashboard tracks the whole business rather than one book: current priorities, products, sales and publishing channels, Amazon KDP, marketing, milestones and settled operating rules.

## Daily use

1. Open **Overview**.
2. Read **Do This Next**.
3. Work on that action before adding new projects.
4. Update its status in **Action Board**.
5. Use **Sales Channels** and **Marketing** to check distribution and promotion.

The dashboard stores manual status changes in the browser. Use **Back up dashboard** to export a JSON backup.

## Safety

This repository and GitHub Pages site are public. Never store passwords, bank details, identity documents, access tokens, private manuscript text or private storage links in the dashboard.
