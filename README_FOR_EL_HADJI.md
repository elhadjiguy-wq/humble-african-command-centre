# AISHA PUBLISHING COMMAND CENTRE

## WHAT THIS APP DOES

This is your private publishing control room for **Aisha: A Daughter of the Savannah**. It shows what is ready, what needs attention, and the single best thing to do next. It also keeps your book information, file records, store progress, artwork plans, marketing work, timeline and decisions together.

The app does **not** publish, buy, email, or send anything. It does not ask for passwords or bank numbers. Your information stays in the web browser on this computer.

## HOW TO START IT

1. Open the folder named `humble-african-command-centre`.
2. Open a Terminal window in that folder.
3. Copy and paste this exact line, then press Enter:

```text
python3 -m http.server 4173
```

4. Open this address in Chrome, Edge, Firefox or Safari:

```text
http://localhost:4173
```

Keep the Terminal window open while using the app.

## HOW TO STOP IT

Go to the Terminal window and press **Control + C**. You can then close the window. Your saved information will still be there next time.

## WHERE MY DATA IS

Your project information is saved by your web browser on this computer. Your actual book and picture files are **not moved or changed**; the Book Files page only records their names and purposes.

Always open the app with the same browser and the same address (`http://localhost:4173`). Clearing all browser data can remove the saved information, so make backups regularly.

## HOW TO BACK IT UP

1. Open the app.
2. Press **Back up my project** at the top right.
3. A dated backup file will appear in your Downloads folder.
4. Keep a second copy on a USB drive or trusted cloud folder.

To make a readable paper or PDF report, open the page you want, press **Control + P** (or **Command + P** on a Mac), and choose **Save as PDF**.

## HOW TO RESTORE IT

Restoring a backup is intentionally a careful, manual step so an older copy cannot silently overwrite your current work. Keep the downloaded backup safe. Ask a trusted technical helper to restore that file into the app. They should first make another backup of the current information.

## WHAT TO DO IF SOMETHING GOES WRONG

1. Do not delete anything.
2. Close the browser tab and stop the app with **Control + C**.
3. Start it again using the instructions above.
4. Confirm that the address is exactly `http://localhost:4173` and that you are using your usual browser.
5. If your information is missing, stop and find your latest `Aisha_Project_Backup` file. Do not create lots of new work before restoring it.

Open **Today** and complete only **Today's #1 Priority**. The app will then move the next useful task to the top.
